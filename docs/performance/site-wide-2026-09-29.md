## Concrete reductions

1. Added `prefetch={false}` to 87 remaining links across 28 components/pages. This includes the always-visible home brand and Analysis/BankScope tabs, and removes search-highlight prefetch. Links still use ordinary client navigation when selected. An AST regression scans every Next Link in `src`.
2. Fixed deadline-aware cache single-flight. Twenty simultaneous equal reads require one RPC rather than twenty in deterministic tests. Each waiter keeps its own abort/deadline, and writes still invalidate old read generations.
3. Removed the second Supabase *miss* lookup only after a validated steady Redis-migration control observation. Existing Redis fallback is preserved. The control decision expires after 60 seconds, shorter than the migration worker's ten-minute drain before copy/delete. Unknown/migrating state and real read errors retain retry recovery. Fixtures: 100 sequential misses use 101 total RPCs instead of 200; 1,000 batched IDs use 41 instead of 80. These are mechanism tests, not a forecast for aggregate bills.
4. Funding/Derivatives public snapshots share a 15-minute validated Data Cache boundary. Failed refreshes preserve a last-good result with a retained label; entries older than six hours must recheck the origin. On failure, the existing labeled fallback may retain older source data; this is not a new source-age limit. Payload/source timestamps are not renewed. Workload identity is never cached in the result. Fresh ready server data does not immediately download again during hydration; stale/retained data and manual retry still recheck.
5. Chart parent boxes retain their heights. SVG trees mount only when near the viewport and measured at positive dimensions. The CFTC history disclosure retains its keyboard-accessible summary while closed and builds its full table on expansion.

## SEO safeguards

All public page files have route metadata or an intentional redirect. Sitemap URLs are canonical, unique, query-free, and discover active analysis coverage. All 500 bundled active issuers remain included; removed featured issuers cannot linger independently of active coverage. Private workspaces, custom comparisons, invalid/missing identities and protected operational surfaces retain appropriate indexing exclusions. Public research JSON crawler exceptions are unchanged.

## Verification and measurement limits

- Local regression run: 3,942 passed, two opt-in/unsupported-environment tests skipped; isolated SQL recovery rehearsal: 10 passed. Final lint, typecheck, build and hosted CI are checked before rollout.
- New regression suites cover navigation budgets, chart deferred geometry, initial snapshot refresh decisions, shared public market reads, route metadata and cache retry/coalescing behavior.
- Baseline bounded HTTP probes returned 200 for home, Analysis, BankScope directory, Funding, Derivatives, robots.txt and sitemap.xml. Funding/Derivatives and Analysis were `private/no-store` despite page revalidation declarations, motivating the explicit public read boundary. Network transit in the audit environment prevents treating the observed 4–6-second request times as page-performance benchmarks.
- Full route/API cold-path behavior still depends on deployed workload identity and production data; preview/local execution is not proof of production-data behavior.
- Compare postdeployment traffic over matched windows and the same RPC families. Concurrent-hit/miss proportions determine savings; this review does not claim an overall percentage or erase previously accumulated usage. Existing SEC acquire/release coordination and scheduled refresh coverage are deliberately preserved.
